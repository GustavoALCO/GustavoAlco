## Gustavo Alves

**`Desenvolvedor Full Stack | .NET | Angular | Python`**

Sou formado em **Ciência da Computação pela Universidade Nove de Julho (UNINOVE)**

Atualmente, atuo na ARSESP (Agência Reguladora de Serviços Públicos do Estado de São Paulo), com atividades relacionadas ao desenvolvimento, manutenção e evolução de sistemas, incluindo a responsabilidade pela manutenção de uma API e de uma aplicação, além de automação de processos e análise de dados.

Tenho experiência prática no desenvolvimento de aplicações utilizando **C#, Flutter e Angular**, com foco em boas práticas de programação, arquitetura limpa, integração de sistemas e desenvolvimento de APIs REST.

Também desenvolvo soluções voltadas à **automação de processos, tratamento e análise de dados**, utilizando Python, Pandas, NumPy, Scikit-learn e Plotly para criação de gráficos interativos e visualização de indicadores.

Possuo conhecimentos em **PostgreSQL, Docker, Git e GitHub**, aplicados à organização de projetos, manipulação de bancos de dados, versionamento e gerenciamento de ambientes de desenvolvimento.
